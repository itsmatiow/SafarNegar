# 🌍 SafarNegar

A travel planning web application built with **React**, **Vite**, and **Leaflet**.

SafarNegar helps users explore destinations, view them on an interactive map, and plan their trips through a responsive web interface.

## ✨ Features

* Explore travel destinations
* Interactive map with Leaflet
* View destinations on the map
* Plan and organize trips
* Date selection for travel planning
* Client-side routing
* Responsive interface

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/itsmatiow/SafarNegar.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

For the local JSON Server:

```bash
npm run server
```

Then open the local URL shown in your terminal.
